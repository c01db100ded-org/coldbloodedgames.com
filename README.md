# Coldblooded Games — coldbloodedgames.com

Official site for **Coldblooded Games**, maker of tactical crown-and-fortress games.

The site is a static home page plus legal pages, hosted on GitHub Pages.

- Home: `index.html`
- Privacy Policy: `privacy-policy.html`
- License Terms: `terms-license.html`
- Terms of Service: `terms-of-service.html`

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000/
```

No build step required.

## Publishing

Pushes to `main` deploy to GitHub Pages automatically.
